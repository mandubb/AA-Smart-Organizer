## 🎯 How to Use

### Launch the Application
```bash
python main.py
```

### First Time Setup
1. Application opens with default profile
2. Browse to a folder
3. Try "👁️ Preview Clean" to see what's junk
4. Use "✨🧹 Organize + Clean" for full cleanup

### Create Client Profile
1. Click "➕ New" in profile section
2. Enter client name
3. Profile is created with separate config
4. Switch between profiles using dropdown
